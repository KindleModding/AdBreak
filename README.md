# AdBreak

AdBreak is a jailbreak created by hhhhhhhhh, supporting `5.18.1` - `5.18.5.0.1` on registered, ad-supported models.

> [!NOTE]
> AdBreak does not support the Kindle Scribes, or Coloursofts, as these cannot be ad-enabled*.

Please see the guide [here](https://kindlemodding.org/jailbreaking/AdBreak/).

## Special Thanks

- H^9, Jailbreak Creator.
- Penguins184, Guide Author. The JB has been modified to work with `jb.sh`/`hdnext`.

*The KS1 (2022) had a workaround, where advertisements could be enabled manually on specifically French Amazon accounts. Whether or not this is patched is unclear.
